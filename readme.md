# 🔬 Simulador de Separación de Mezclas

Simulador web educativo e interactivo diseñado para estudiantes de **6° Grado de Educación Básica Secundaria**. Permite experimentar virtualmente con mezclas homogéneas y heterogéneas, reforzando la comprensión de conceptos como solubilidad, magnetismo, densidad y tamaño de partículas.

---

## 🎯 Objetivos de Aprendizaje

- Diferenciar entre **mezclas homogéneas** y **heterogéneas**.
- Reconocer y aplicar las técnicas fundamentales de laboratorio:
  - **Filtración** (agua y arena).
  - **Decantación** (agua y aceite).
  - **Imantación** (arena y limaduras de hierro).
  - **Evaporación** (agua con sal).
  - **Tamizado** (harina y arroz).
- Identificar la **propiedad física** que permite la separación en cada caso.

## 🚀 Despliegue en GitHub Pages (Paso a Paso)

1. En tu repositorio de GitHub, ve a la pestaña **Settings** (Configuración).
2. En el menú lateral izquierdo, selecciona **Pages**.
3. En la sección **Build and deployment**:
   - Source: `Deploy from a branch`.
   - Branch: Selecciona `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save**.
5. En un par de minutos, GitHub generará tu enlace público (ejemplo: `https://tu-usuario.github.io/separacion-mezclas-simulador/`).
